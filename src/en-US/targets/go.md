## How to read it {#reading}

Go has no generics-free way to express some Faber types, so the emitter materialises helpers the source never wrote. Borrow modes (`de` / `in` / `ex`) erase here — they lower, but they do not survive as distinctions.

func faberTensorOffset(shape []int, rawIndices any) *int {
    const maxInt = int(^uint(0) >> 1)
    indices := faberIndexSlice(rawIndices)
    if len(indices) != len(shape) { return nil }
    offset := 0
    stride := 1
    for axis := len(shape) - 1; axis >= 0; axis-- {
        idx := indices[axis]
        dim := shape[axis]
        if dim < 0 || idx < 0 || idx >= dim { return nil }

        offset += idx * stride
        if dim > 0 && stride > maxInt/dim { return nil }

    }
    return &offset
}
