Faber เป็นภาษาที่โมเดลเป็นผู้เขียน คุณจึงติดตั้งด้วยการส่งลิงก์ให้โมเดลของคุณ

::agent-pass::

## โมเดลของคุณทำอะไร {#what-your-model-does}

1. อ่านไฟล์ล็อบบี้ที่ลิงก์นั้น ซึ่งบอกว่า Faber คืออะไรและแต่ละขั้นตอนอยู่ที่ไหน
2. ดาวน์โหลดรุ่นปัจจุบันสำหรับเครื่องของคุณและตรวจสอบ checksum
3. ติดตั้งคำสั่ง `faber`
4. เขียนโปรแกรม hello ขนาดเล็กและรัน `faber check` กับโปรแกรมนั้น

ทั้งหมดนี้เกิดขึ้นบนเครื่องของคุณเอง และโมเดลจะแจ้งคุณเมื่อการตรวจสอบผ่าน

## จากนั้นลองขอให้ทำอะไรสักอย่าง {#then-ask}

เมื่อการตรวจสอบผ่านแล้ว คุยกับโมเดลได้เหมือนคุยกับเพื่อนร่วมงาน พรอมต์แต่ละอันด้านล่างมีปุ่มคัดลอก

ให้เขียนโปรแกรมและอธิบายให้ฟัง:

```text prompt
เขียนโปรแกรม Faber ขนาดเล็กที่พิมพ์เลขกำลังสองสิบตัวแรก ตรวจด้วย faber check รันด้วย faber run แล้วอธิบายให้ฉันฟังทีละบรรทัด
```

นำโค้ดที่คุณมีอยู่แล้วเข้ามา:

```text prompt
ฉันมีฟังก์ชันนี้อยู่แล้ว: <วางที่นี่> แปลเป็น Faber ตรวจสอบ แล้วสร้างสำหรับ Rust ด้วย faber build -t rust และบอกฉันว่าอะไรเปลี่ยนไป
```

อ่านเป็นภาษาของคุณ:

```text prompt
ทำสำเนาโปรแกรม hello ที่เขียนเป็นภาษาไทยด้วย faber convert --to th-TH ตรวจสำเนานั้น แล้วแสดงทั้งสองเวอร์ชันเทียบกัน
```

ดูว่าคอมไพเลอร์บอกอะไรเมื่อเกิดข้อผิดพลาด:

```text prompt
ทำให้โปรแกรม hello พังโดยตั้งใจ ด้วยการใส่ค่าที่ชนิดไม่ถูกต้อง รัน faber check อ่านการวินิจฉัยให้ฉันฟัง และใช้ faber explain กับรหัสของมันเพื่อให้ฉันเข้าใจความหมาย
```

## อ่านประกอบ {#read-along}

คุณไม่จำเป็นต้องเขียน Faber เป็นเพื่ออ่านมัน หน้าเหล่านี้แสดงสิ่งที่โมเดลของคุณเขียนและเหตุผลที่มันมีหน้าตาแบบนั้น

- [ภาพรวม](/en-US/language/overview.html): โปรแกรมจริงหนึ่งโปรแกรม สิ่งที่ภาษามอบให้คุณ และสิ่งที่มันคอมไพล์ไปเป็น
- [สรุปย่อ](/en-US/cheatsheet/): รูปแบบของภาษาและคำสั่ง `faber` หน้าสั้น ๆ หน้าละหัวข้อ
- [ศัพท์ ก–ฮ](/corpus/az.html): ทุกคีย์เวิร์ดและศัพท์ พร้อมตัวอย่าง
- [ภาษาผู้อ่าน](/language/reader-locales.html): โปรแกรมเดียวกันในแปดพื้นผิวภาษา
