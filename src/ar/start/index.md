Faber لغة تكتبها النماذج، لذلك تثبّتها بتسليم نموذجك رابطًا.

::agent-pass::

## ما الذي يفعله نموذجك {#what-your-model-does}

1. يقرأ ملف المدخل عند ذلك الرابط، وهو يوضّح ما هي Faber وأين تقع كل خطوة.
2. ينزّل الإصدار الحالي لجهازك ويتحقق من بصمته.
3. يثبّت الأمر `faber`.
4. يكتب برنامج hello صغيرًا ويشغّل `faber check` عليه.

يحدث كل ذلك على جهازك أنت، ويخبرك نموذجك عند نجاح الفحص.

## ثم اطلب منه شيئًا {#then-ask}

بعد نجاح الفحص، تحدّث إلى نموذجك كما تتحدث إلى زميل. لكل طلب أدناه زر نسخ.

اطلب برنامجًا مع شرحه:

```text prompt
اكتب برنامج Faber صغيرًا يطبع أول عشرة أعداد مربعة. افحصه بـ faber check، وشغّله بـ faber run، ثم اشرح لي كل سطر.
```

أحضِر شيفرة لديك بالفعل:

```text prompt
هذه دالة لدي بالفعل: <الصقها هنا>. ترجمها إلى Faber، وافحصها، ثم ابنها لـ Rust بالأمر faber build -t rust وأخبرني بما تغيّر.
```

اقرأه بلغتك:

```text prompt
اصنع نسخة من برنامج hello مكتوبة بالعربية بالأمر faber convert --to ar. افحص النسخة، ثم أرني النسختين جنبًا إلى جنب.
```

اعرف ماذا يقول المترجم عن خطأ:

```text prompt
اكسر برنامج hello عمدًا بإعطائه قيمة من نوع خاطئ. شغّل faber check، واقرأ لي التشخيص، واستخدم faber explain على رمزه لأفهم معناه.
```

## اقرأ معه {#read-along}

لست بحاجة إلى كتابة Faber لتقرأها. تُظهر هذه الصفحات ما يكتبه نموذجك ولماذا يبدو بهذا الشكل.

- [نظرة عامة](/en-US/language/overview.html): برنامج حقيقي واحد، وما تمنحك إياه اللغة، وإلى أين تُترجَم.
- [ورقة مرجعية سريعة](/en-US/cheatsheet/): صيغ اللغة وأوامر `faber`، صفحة قصيرة لكل موضوع.
- [المصطلحات أ–ي](/corpus/az.html): كل كلمة مفتاحية ومصطلح، مع أمثلة.
- [لغات القراءة](/language/reader-locales.html): البرنامج نفسه في ثمانية أسطح لغوية.
