# ?(

Null-safe member, index, and call access.

**Term** `?(` · **Section** OPERATORS

## Syntax

```
<expression>?.<name> | <expression>?[<expression>] | <expression>?(<args>)
```

## What this teaches

- Optional chaining — `?.` accesses fields only when the receiver is present, returning `none` otherwise.
- Index and call safety — `?[ ]` for safe index access, `?( )` for safe call on optional values.

## Common mistakes

- Chaining too deeply — each ?. that hits none short-circuits, making debugging harder.

## Grammar

```
optionalSuffix :← '?.' IDENTIFIER | '?[' expr ']' | '?(' argumentList ')'
```

## Expected output

```
Roma, Italia, nihil, nihil, a, nihil
```

## Example

```fab
class Locus {
    var string urbs
    var string regio optional
}

class Civis {
    var string nomen
    var Locus locus optional
}

main {
    const Civis aelia ← Civis { nomen = "Aelia", locus = Locus { urbs = "Roma", regio = "Italia" } }
    print aelia?.locus?.urbs
    print aelia?.locus?.regio
    const Civis brutus ← Civis { nomen = "Brutus" }
    print brutus?.locus?.urbs
    print brutus?.locus?.regio
    const list<string, 3> litterae ← ["a", "b", "c"]
    print litterae?[0]
    print litterae?[10]
}
```
