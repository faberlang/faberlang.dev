# ?(

A `?(` call runs only when the function value is present, and gives `none` when it is absent.

**Term** `?(` · **Section** OPERATORS

## Syntax

```
<expression>?(<args>)
```

## What this teaches

- `f?(x)` calls the optional function value `f` only when it is present; when `f` is `none` the call does not run and the result is `none`
- The result is `T ∪ none`, so a `coalesce` default can fill in the absent case

## Common mistakes

- Expecting an absent function to give a default value: it gives `none`, and `coalesce` supplies the default

## Example

```fab
type Op = (int) → int

main {
    let Op ∪ none present ← int x → int ∴ x * 2
    let Op ∪ none absent ← null
    print present?(5)
    print absent?(5)
    print absent?(5) coalesce -1
    let int ∪ none found ← present?(1)
    print found
}
```
