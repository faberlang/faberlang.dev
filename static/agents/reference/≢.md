# ≢

Equality and ordering comparisons returning bool.

**Term** `≢` · **Section** OPERATORS

## Syntax

```
<expression> ≡ <expression> | <expression> ≢ <expression> | <expression> ≤ <expression> | <expression> ≥ <expression>
```

## What this teaches

- Comparison operators — `≡` (equal), `≢` (not equal), `≤` (less-or-equal), `≥` (greater-or-equal).
- Chaining — Comparisons can be chained with `and` for interval tests like `0 < x and x < 10`.

## Common mistakes

- Using == instead of ≡ for equality, or != instead of ≢ for inequality — Faber uses Unicode operators.

## Grammar

```
cmpExpr :← expr ('≡' | '≢' | '≤' | '≥' | '<' | '>') expr
```

## Backend

```
Scalar bivalens stdout; chain with et for interval tests.
main {
    let bool aequalis ← 10 ≡ 10
    print aequalis
    let bool diversus ← 10 ≢ 5
    print diversus
    let bool nonMaior ← 5 ≤ 10
    print nonMaior
    let bool nonMinor ← 10 ≥ 5
    print nonMinor
    let bool in_range ← 0 ≺ 5 and 5 ≺ 10
    print in_range
}
```

## Example

```fab
test "equal and not-equal comparisons" {
    assert 10 ≡ 10
    assert 10 ≢ 5
}

test "ordering and chained interval" {
    assert 5 ≤ 10
    assert 10 ≥ 5
    assert 0 ≺ 5 and 5 ≺ 10
}
```
