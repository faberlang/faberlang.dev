# f16

the bare `f16` type-position width marker.

**Term** `f16` · **Section** TYPES

## Syntax

```
f16
```

## What this teaches

- the bare `f16` type-position width marker.
- Related keywords: float, matrix

## Common mistakes

- Writing a float width as an argument of another type — the marker itself is the type (`f16`, `f32`, `f64`).
