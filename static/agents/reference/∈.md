# ∈

Checks whether a value appears in a collection.

**Term** `∈` · **Section** OPERATORS

## Syntax

```
<expression> ∈ <collection>
```

## What this teaches

- Checks whether a value appears in a collection.
- Related operators: ‥, …

## Common mistakes

- Using `∈` with a non-collection right operand — `∈` checks membership in a list, map, or set (or a range), and a scalar right operand is rejected (SEM010); for a substring test on text use `contains`.

## Grammar

```
membershipExpr :← expr '∈' expr
```

## Example

```fab
main {
    const string condicio ← "agens"
    const int aetas ← 21

    # Basic ∈ with string list
    if condicio ∈ ["pendens", "agens", "pausa"] {
        print "condicio valida"
    }

    # ∈ with numeric list
    if aetas ∈ [18, 21, 65] {
        print "aetas insignis"
    }
    print "exempla ∈"
}
```
