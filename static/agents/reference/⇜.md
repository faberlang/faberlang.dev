# ⇜

Sink-into writes one exactly typed item with ⇜, the operator form of sink.sink(item).

**Term** `⇜` · **Section** OPERATORS

## Syntax

```
<mut Sink<T>> ⇜ <T>
```

## What this teaches

- `sink ⇜ item` is the statement form of `sink.sink(item)`
- The item must be exactly the `T` in `Sink<T>`; the operator does not implicitly convert it
- A sink chooses its own meaning for one item and for `flush()` The local contract below is the same marked Sink<T> contract Norma exports. `TextSink` records exact items so both the method and glyph forms are visible.

## Example

```fab
@ radix contract "sinking"
interface Sink<T> {
    fn sink(T item) → void ⇥ string
    fn flush() → void ⇥ string
}

class TextSink implements Sink<string> {
    mut list<string> items = empty

    fn sink(string item) → void ⇥ string {
        self.items.append(item)
    }

    fn flush() → void ⇥ string {
    }
}

fn write(mut TextSink sink) → void ⇥ string {
    sink.sink("method")
    sink ⇜ "operator"
    sink.flush()
}

main args args {
    if args.length() ≻ 0 {
        assert args[0] ≡ "sink"
    }

    mut TextSink sink ← TextSink { items = [] }
    do {
        write(mut sink)
    }
    catch error {
        print error
    }
    print sink.items
}
```
