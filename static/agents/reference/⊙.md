# ⊙

Glyph Hadamard: identical-shape elementwise product on vectors, matrices, and tensors.

**Term** `⊙` · **Section** OPERATORS

## Syntax

```
<expression> ⊙ <expression>
```

## What this teaches

- Hadamard product — `a ⊙ b` multiplies elementwise under an identical-shape contract
- Shape families — vectors, matrices, and tensors all lower; tensors route through the shared kernel

## Common mistakes

- shape mismatch — `⊙` rejects differing shapes at compile time (no broadcast stretch)
- confusing `⊙` with `×` — cross is width-3 only; Hadamard is elementwise for any identical shape

## Expected output

```
[4.0, 10.0, 18.0]
[[16.0, 25.0], [64.0, 100.0], [144.0, 225.0]]
[1.0, 4.0, 9.0, 16.0]
```

## Example

```fab
main {
    let vf32[3] a ← [1.0, 2.0, 3.0] ↦ vf32[3]
    let vf32[3] b ← [4.0, 5.0, 6.0] ↦ vf32[3]
    let vf32[2] q ← [4.0, 5.0] ↦ vf32[2]
    let matrix<f32, [3, 2]> o ← a ⊗ q

    let vf32[3] v ← a ⊙ b
    print v

    let matrix<f32, [3, 2]> m ← o ⊙ o
    print m

    let list<f32> flat_a ← [1.0, 2.0, 3.0, 4.0]
    let list<f32> flat_b ← [1.0, 2.0, 3.0, 4.0]
    mut tf32[2, 2] ta ← flat_a ↦ tf32[2, 2]
    mut tf32[2, 2] tb ← flat_b ↦ tf32[2, 2]
    let tf32[2, 2] t ← ta ⊙ tb
    let list<f32> out ← t.flatten()
    print out
}
```
